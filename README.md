# Vidriera

Agencia de webs para comercios de barrio en Buenos Aires, de Santiago Bertone.

- [`vidriera/`](vidriera/): el sitio de la agencia y las demos por rubro (odontología y cerrajería). Ver su [README](vidriera/README.md).
- [`CONTEXTO_PROYECTO.md`](CONTEXTO_PROYECTO.md): todo el contexto del negocio y del proyecto. Leelo antes de seguir trabajando, sobre todo si lo retomás con Claude en otra computadora.
- `Prospectos_Vidriera.xlsx`: planilla de prospectos.

## Trabajar desde otra computadora

```bash
git clone https://github.com/SantBertone/portfoliowebpages
```

Antes de empezar, `git pull`. Al terminar, `git add -A`, `git commit` y `git push`.
